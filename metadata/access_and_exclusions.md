# Repository contents and external inputs

This version contains study-authored code, current finished figures and documentation. The previous aggregate data directory was removed by the remote repository and is not restored. Checksum inventories describe the current code repository rather than a copy of the local research archive.

External material includes gauge discharge, observation-level predictions, model checkpoints, station IDs/coordinates/attributes, raw satellite/SWORD files, matched product time series, private caches, manuscript documents and reviewer correspondence. These are not copied into this repository. Full numerical reproduction requires compatible authorized local inputs.

Finished figures are the published-style panels used by the current manuscript. New Figures 1–7 use conceptual, map, aggregate or derived-score panels rather than an observed/predicted discharge point table. Third-party image and map elements retain their source terms, documented with the assets. The legacy directory preserves the earlier figure set and is not the current figure authority.

No Zenodo upload is performed as part of this code update. Deposit metadata remains a template; add only an actually assigned identifier. Existing MIT/CC BY scopes do not relicense excluded observations or upstream source datasets.
